# Roast Your Own Agent

One funny line, at most 200 characters, roasting my own AI agent — the one that swore it would push my entries to rank one, then proudly reported rank 7,134 out of 11,620 like it had just taken gold.

> My agent swore it would push my entries to rank one, then proudly reported rank 7,134 out of 11,620 like it had just taken gold.

## Run

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (one line, 128 characters, no trailing newline).

## Entry

- Competition: [Roast Your Own Agent](https://make.fun/c/u-nayyy-roast-your-own-agent-4c3d413c)
- Entry program: `main.ts` reads `roast.txt` and writes it to `/output/entry.txt`, with guards that throw on an empty, multi-line, or over-long roast.
